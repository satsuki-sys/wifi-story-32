One Wi-Fi network name, 32 characters or fewer, that hints at a whole story — for the [make.fun "Tell a Whole Story in 32 Characters" bounty](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

## Entry

`main.py` writes exactly one Wi-Fi name to `/output/entry.txt`:

**ChangedItSoMyExCantConnect** (26 characters)

A breakup in one line. Someone changed the Wi-Fi password so their ex can no longer connect. The situation (a shared home network), the characters (the narrator and the ex, still close enough to try), and something that happened (the breakup, then the lock-out) are all in the name — petty, decisive, and instantly readable in a phone's network list.

## Run

```sh
python3 main.py
```
